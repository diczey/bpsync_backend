GERÇEK CİHAZDA TEST ADIMLARI
============================

1. BİLGİSAYAR VE TELEFON AYNI WiFi'DE OLMALI
   (Aynı modem/router'a bağlı)

2. BİLGİSAYARIN IP ADRESİNİ BULUN
   Windows (CMD veya PowerShell):
     ipconfig
   "Wireless LAN adapter Wi-Fi" veya "Ethernet" altında
   "IPv4 Address" satırına bakın (örn. 192.168.1.50)

   Mac/Linux:
     ifconfig
   veya
     ip addr

3. BACKEND'İ ÇALIŞTIRIN (bilgisayarda)
   cd backend
   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

   Önemli: --host 0.0.0.0 olmalı (sadece localhost değil),
   yoksa telefon bilgisayara bağlanamaz.

4. ApiConstants.kt İÇİNDE DEĞİŞTİRİN
   - USE_REAL_DEVICE = true
   - REAL_DEVICE_IP = "192.168.1.50"  (kendi IP'nizi yazın)

5. UYGULAMAYI TELEFONA YÜKLEYİN
   USB ile bağlayın veya APK paylaşın.
   Run > Run 'app' ile gerçek cihazı seçin.

6. WINDOWS FIREWALL
   İlk seferde "Python" veya "uvicorn" için erişime izin verin.
   Gerekirse port 8000 için izin ekleyin.

7. TEST
   Uygulamada giriş yapın; backend'den veri geliyorsa bağlantı çalışıyordur.
   Gelmiyorsa: IP doğru mu, backend çalışıyor mu, aynı WiFi mi kontrol edin.
